# MODERN-VOICE-CALCULATOR


A **feature-MODERN VOICE Calculator** built with **HTML, CSS, and JavaScript**.  
It includes standard & voice input 🎤,sound effects 🔊, and a modern glassmorphism UI ✨.  

---



---

## ✨ Features
- ✅ Standard calculator functions (Add, Subtract, Multiply, Divide)   
- ✅ Voice Input using Web Speech API  
- ✅ Sound & animation feedback on every button  
- ✅ Responsive modern UI (Glassmorphism + Gradient)  

---

## 🛠 Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- Web Speech API  

---


## 💡 Learning

- Creating modern UI with glassmorphism and neon effects
