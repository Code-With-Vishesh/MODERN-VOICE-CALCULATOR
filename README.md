## 🌟 About The Project

**Modern Voice Calculator** is a modern, responsive and interactive calculator designed to make calculations faster and more enjoyable.

Instead of relying only on traditional buttons, users can interact with the calculator using **voice commands**.

The project combines:

* 🎙️ Voice input
* 🧮 Real-time calculations
* 🌙 Day / Night theme
* ✨ Modern glassmorphism UI
* 📱 Mobile-friendly layout
* ⚡ Smooth animations
* 🔢 Mathematical expression support
* 🎨 Interactive calculator buttons

The main goal of this project was to create a calculator that feels more like a **modern digital assistant** rather than a traditional calculator.

# 🎙️ Voice Calculator

The most interesting feature of this project is the **voice interaction system**.

Instead of manually entering:

```text
25 + 35
```

you can speak the expression naturally.

The calculator processes the spoken command and converts it into a mathematical expression.

### Example Commands

```text
10 plus 20
```

```text
50 minus 15
```

```text
8 multiplied by 5
```

```text
100 divided by 4
```

The goal is to make mathematical calculations feel more natural and accessible.

---

# 🌙 Day & Night Theme

The calculator includes a theme switcher that allows users to change the visual appearance.

### ☀️ Light Mode

Clean and bright interface suitable for daytime use.

### 🌙 Dark Mode

A darker interface designed for comfortable nighttime use.

The theme transition is designed to feel smooth rather than simply switching instantly.
